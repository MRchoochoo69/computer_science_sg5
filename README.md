#Sean Francis C. Cacatian's Improved Distance Calculator

##Description
This is my improved version of the Distance Calculator from KHUB-IRC SG5, a program that calculates the distance between two points by using the input coordinates.

##How to Run
Open the python file in any valid Python compiler, such as the Terminal or Programiz.

##Required Inputs
Coordinates of point 1: X1, Y1
Coordinates of point 2: X2, Y2

##Sample Output
Enter X1: 5
Enter Y1: 5
Enter X2: 1
Enter Y2: 2
Distance: 5.0
